# Shape

List of shape tokens. One primitive radius; two derived steps.

| Token | Value | Tailwind | Usage |
| --- | --- | --- | --- |
| `--radius` | `0.625rem` (10px) | `rounded-lg` | Cards, buttons, inputs |
| `--radius - 2px` | `0.5rem` | `rounded-md` | Inner elements |
| `--radius - 4px` | `0.375rem` | `rounded-sm` | Badges, pills |
| `rounded-full` | `9999px` | `rounded-full` | Avatars, scrollbar thumb |
