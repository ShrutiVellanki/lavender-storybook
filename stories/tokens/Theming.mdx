# Theming

Tokens that change between Lavender Dawn (`:root`) and Lavender Moon (`.dark`). The names stay; the primitives swap. Components read the names.

```
<html>              →  Dawn  →  :root
<html class="dark"> →  Moon  →  .dark
```
