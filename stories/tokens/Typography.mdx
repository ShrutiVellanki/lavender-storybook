# Typography

Styles alias primitives. `100` is 16px. `body` is set on the document.

---

## Primitive typography

Primitive tokens include font family, font size, font weight, line height, and letter spacing.

### Font family

| Token | Value |
| --- | --- |
| `--font-sans` | Inter, ui-sans-serif, system-ui, sans-serif |

### Font size

| Token | Value |
| --- | --- |
| `--text-size-50` | 12px |
| `--text-size-75` | 14px |
| `--text-size-100` | 16px |
| `--text-size-300` | 24px |

### Font weight

| Token | Value |
| --- | --- |
| `--text-weight-regular` | 400 |
| `--text-weight-medium` | 500 |
| `--text-weight-semibold` | 600 |

### Line height

| Token | Value |
| --- | --- |
| `--text-leading-none` | 1 |
| `--text-leading-tight` | 1.25 |
| `--text-leading-loose` | 1.6 |

### Letter spacing

| Token | Value |
| --- | --- |
| `--text-tracking-tight` | −0.01em |
