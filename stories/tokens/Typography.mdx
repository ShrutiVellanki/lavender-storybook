# Typography

List of typography tokens. Family, tracking, and line height are global. Size and weight are what components choose.

| Token | Value |
| --- | --- |
| Family | Inter |
| Tracking (body) | `-0.011em` |
| Line height | `1.6` |
| Features | `cv02`, `cv03`, `cv04`, `cv11` |
