# Size

List of size tokens. Control height and spacing.

| Token | Height | Padding | Type | Usage |
| --- | --- | --- | --- | --- |
| `sm` | 32px (`h-8`) | `px-3` | 12px | Compact toolbars, table actions |
| `default` | 36px (`h-9`) | `px-4` | 13px | Primary density |
| `lg` | 40px (`h-10`) | `px-5` | 13px | Standalone CTAs |
| `icon` | 32×32 (`h-8 w-8`) | — | — | Icon-only |
