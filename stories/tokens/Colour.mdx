# Colour and Theming

## Theme switching

Lavender Dawn is light. Lavender Moon is dark. In Storybook, switch them from the toolbar. In product, `ThemeSwitcher` adds or removes `class="dark"` on the document. `.dark` remaps `--colour-*` primitives only, so semantic `--color-*` tokens keep the same names and follow the theme without component changes.

`--colour-*` primitives are the raw scale. `--color-*` semantic tokens alias those primitives by role: `--color-background` is `--colour-base`, `--color-success` is `--colour-pine`, `--color-focus` is `--colour-iris`.
