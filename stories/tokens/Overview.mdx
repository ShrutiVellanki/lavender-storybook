# Tokens

Two layers. **Primitive tokens** are raw values: iris `#907aa9`, radius `0.625rem`, Inter at 14px. **Semantic tokens** are names for intent: `--primary`, `--radius`, `--foreground`. Components bind to semantics. Themes (and brands) reassign primitives underneath. Swap the mapping, leave the component file alone.

| | Primitive | Semantic |
| --- | --- | --- |
| Meaning | A concrete value | A role in the UI |
| Example | `#907aa9`, `0.625rem`, `12px` | `--primary`, `--radius`, `text-xs` |
| Changes when | A brand or theme is designed | Almost never — the name is the API |
| Who uses it | Token files (`:root`, `.dark`, `lavenderDawn.*`) | Components (`bg-primary`, `rounded-lg`) |

---

**Colour.** Primitive tokens are the palettes (`lavenderDawn.iris`, `lavenderMoon.love`). Semantic tokens are roles (`--primary`, `--destructive`, `--chart-1`) so a theme switch reassigns iris without touching Button.

**Typography.** Tokens here are family (Inter), size (`text-xs` … `text-2xl`), weight, tracking, and line height. Size and weight are the ones components actually pick; family and tracking are global.

**Size.** Control height (`sm` 32px, `default` 36px, `lg` 40px, `icon` 32×32) and spacing steps (`p-2` … `p-6`). Density, not visual style.

**Shape (border radius).** One primitive `--radius` (10px). Semantic steps are derived: `rounded-lg` / `md` / `sm`.

**Elevation.** Three roles — flat (border), raised (`shadow-sm`), overlay (`shadow-lg`) — not a hex, a stack order.

**Theming.** The set of semantic colour tokens that have a different primitive in `:root` vs `.dark`. Dawn and Moon are two assignments of the same names.

→ Colour, Typography, Size, Shape, Elevation, Theming in this group.
